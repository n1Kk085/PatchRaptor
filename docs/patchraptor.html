🦖 PatchRaptor Architecture Design

A production-oriented automation toolkit for managing ARK: Survival Ascended dedicated server clusters. Provides Discord-based control, automated patching, backups, player management, cross-server chat relay (RaptorChat), and a branded web dashboard.

🔐 Source-Available

Full source code available for security auditing. No black-box dependencies.

🪟 Windows-Focused

Targets Windows Server 2019/2022 and Windows 10/11. Native subprocess handling.

🔧 Production-Grade

Manual deployment, no CI/CD dependency. Operates in real server environments.

⚡ Performance-Optimized

Atomic file writes, thread-pooled blocking operations, 2s-10s telemetry intervals.

🏗️ Runtime Architecture

Background Task Supervision

All background tasks are supervised via _run_supervisored() wrapper in main.py:

async def _run_supervisored(self, coro, task_name):
    """Run a background task and track its handle for supervision"""
    try:
        task = asyncio.create_task(coro)          ← Fire-and-forget
        task.set_name(task_name)                  ← Naming for logging
        self.background_tasks.append(task)         ← Global tracking

        # Failure callback registered on creation
        def _handle_done(t):
            if t.exception():                      ← Exception detection
                logger.error_system(f"Task '{task_name}' failed: {t.exception()}")

        task.add_done_callback(_handle_done)       ← Callback registration
        return task
    except Exception as e:                         ← Creation failure handling
        logger.error_system(f"Failed to launch task {task_name}: {e}")

Async/Threading Pattern

# Blocking operations MUST use asyncio.to_thread()
result = await asyncio.to_thread(subprocess.run, cmd_args, ...)

# File I/O uses atomic temp file + os.replace() pattern
def _sync_save(self):
    temp_file = self.data_file + ".tmp"        # Write to temp first
    with open(temp_file, 'w') as f:
        json.dump(self.data, f)                 # Minified JSON for speed
    os.replace(temp_file, self.data_file)       # Atomic O(1) rename
📌 Zero-Drift Log Tailing: The Log-Broadcaster resumes from the last read position per server, ensuring no duplicate events and preventing drift across restarts.
